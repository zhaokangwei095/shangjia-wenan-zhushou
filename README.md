# 商家文案助手 · shangjia-wenan-zhushou

帮开店和卖货的人把宣传文案一次写齐的中文 Agent Skill：
小红书笔记、抖音口播、商品标题、详情卖点、直播话术，
外加一遍**广告法违禁词体检**——写得好，更要写得合规。

适用人群：餐饮、美业、零售、民宿、健身等本地商家，
以及淘宝、拼多多、抖店、闲鱼等平台的电商卖家。

## 它能做什么

- **小红书 ×3**：种草版 / 干货版 / 活动版，标题、正文、标签成套
- **抖音口播 ×2**：30 秒 / 60 秒，带前 3 秒钩子和镜头提示
- **商品标题 ×5 + 详情卖点**：属性真实，不蹭无关品牌词
- **直播话术包**：留人、讲品、价格揭晓、售后承诺、救场
- **违禁词体检报告**：绝对化用语、虚假原价、功效承诺逐句标出并改写

> 边界：不编造销量、评价和检测数据，不写医疗功效和收益承诺，
> 不点名诋毁同行。文案的底气来自真实卖点，不是形容词堆砌。

## 安装与使用

把本仓库文件夹放进你的 Agent 的 skills 目录（如 Claude Code 的
`~/.claude/skills/`、Codex/Cursor 等支持 SKILL.md 的工具），
然后直接对 Agent 说：「我开面馆的，新上了番茄牛腩面 28 一碗，
帮我写小红书。」

零依赖小工具（可选，Python 3）：

```bash
echo "全网最低价，最好用的面" | python3 scripts/banned_words_check.py -
# 命中 2 处绝对化用语，并给出改写建议
```

## 目录

- `SKILL.md` — Skill 本体（工作流程、平台写法、自检规则）
- `references/广告法违禁词清单.md` — 高风险词清单与替换思路
- `scripts/banned_words_check.py` — 违禁词自动扫描
- `templates/` — 四个平台的标准版式
- `examples/` — 完整输入→输出示例
